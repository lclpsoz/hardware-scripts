# Agent rules for this repo

**This repository is PUBLIC on GitHub.** Treat every file and every commit as published.

- Never commit personal or device details: MAC addresses, public or private network layout beyond what the docs need, IP addresses of personal machines, usernames, hostnames, serial numbers, tokens, passwords, password hashes, DNS logs, browsing history, work-specific domains.
- Device-specific or personal projects (for example the Jellyfin media server) do not belong here. They live in their own private repos under `~/Code`.
- Do not copy code or notes from private repos into this one without the owner's explicit approval for that specific content.
- Before every commit, scan the staged diff for the items above. If unsure, ask.
- Make small conventional commits, one topic per commit. Do not push without explicit permission each time.
- Do not commit the owner's untracked or modified files outside the area you were asked to work on.
